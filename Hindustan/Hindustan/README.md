# 🎯 AI Speech Therapy Assistant for Disabled Children

## ✅ PROJECT JUSTIFICATION

**Is this NEW?** YES ✓

Existing tools only provide basic speech-to-text or pronunciation games.  
**This project combines:**
- Disability-specific adaptation
- Real-time AI feedback
- Emotion-aware encouragement
- Long-term progress tracking

**One-line justification:**  
*"Existing tools support speech practice, but an AI-based personalized speech therapy assistant that adapts to different disabilities and learning progress is not yet fully developed."*

---

## 🧠 CORE TECHNOLOGIES USED

### 1. **Artificial Intelligence (AI)**
- Intelligent decision-making for personalized feedback
- Adaptive difficulty adjustment based on child's performance

### 2. **Machine Learning (ML)**
- Pattern recognition in speech improvement over time
- Accuracy calculation using similarity algorithms
- Progress prediction and personalized learning paths

### 3. **Speech Processing**
- Real-time speech recognition (Google Speech API)
- Text-to-speech for AI interaction (pyttsx3)
- Audio signal processing and noise filtering

### 4. **Natural Language Processing (NLP)**
- Speech-to-text conversion
- Pronunciation comparison and matching
- Semantic understanding of spoken words

---

## 🚀 FEATURES

✅ **Disability-Specific Adaptation** - Different feedback for stuttering, articulation disorders  
✅ **Real-time Speech Analysis** - Instant pronunciation accuracy scoring  
✅ **Emotional Encouragement** - Child-friendly AI responses  
✅ **Progress Tracking** - Daily improvement stored in JSON database  
✅ **Personalized Learning** - Adjusts difficulty based on performance
